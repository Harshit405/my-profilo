# Harshit Settipalli - Portfolio 💼

A modern, responsive portfolio website showcasing FPGA design, embedded systems, and satellite communication projects with advanced web technologies and best practices.

## ✨ Features

### 🎨 Visual Design
- **Modern Dark/Light Theme Toggle** - Persistent theme preference with system preference detection
- **Smooth Animations** - Fade-in, slide, scale, and parallax animations on scroll
- **Responsive Design** - Mobile-first approach optimized for all devices
- **Gradient Backgrounds** - Eye-catching gradient overlays and color schemes
- **GPU-Accelerated Elements** - Enhanced performance with transform-based animations

### 📱 Interactive Elements
- **Typing Effect** - Animated hero section with character-by-character typing
- **Scroll Indicator** - Animated arrow guiding users to scroll down
- **Smooth Scrolling** - Enhanced navigation with smooth scroll behavior
- **Back-to-Top Button** - Floating button with scroll progress indicator
- **Scroll Progress Bar** - Visual indicator of page scroll position

### 🚀 Performance Optimizations
- **Lazy Loading** - Images load only when visible in viewport
- **CSS Optimization** - Minified and well-organized styles
- **GPU Acceleration** - Transform-based animations for smooth performance
- **Intersection Observer** - Efficient scroll event handling
- **Resource Preloading** - DNS prefetch and font preload for faster loading

### 📊 Content Sections
- **Hero Section** - Eye-catching introduction with CTA buttons
- **About** - Detailed background with animated statistics
- **Experience** - Tabbed interface for education and internships
- **Skills** - Comprehensive skill showcase with tool hierarchy
- **Projects** - 8+ projects with filtering by category
- **Certifications** - Professional credentials and achievements
- **Contact** - Integrated email form with Formspree

### 🔍 SEO Enhancements
- **JSON-LD Structured Data** - Rich snippets for search engines
- **Breadcrumb Schema** - Navigation hierarchy markup
- **Meta Tags** - Comprehensive Open Graph and Twitter Card support
- **Robots.txt** - Crawl directives for search engines
- **Sitemap.xml** - Complete site structure for indexing
- **Mobile Meta Tags** - Apple and Android-specific optimizations

### ♿ Accessibility
- **Semantic HTML** - Proper heading hierarchy and structure
- **ARIA Labels** - Descriptive labels for buttons and links
- **Keyboard Navigation** - Full keyboard support (T for theme toggle)
- **Color Contrast** - WCAG-compliant color ratios
- **Focus States** - Clear visual feedback for focused elements

### 📲 PWA Support
- **Web App Manifest** - App installation capability
- **Service Worker Ready** - Progressive enhancement framework
- **Offline Support** - Cached resources for offline viewing
- **App Shortcut** - Quick access to Projects and Contact

## 🛠️ Technology Stack

- **HTML5** - Semantic markup and structured data
- **CSS3** - Advanced animations, gradients, and responsive design
- **JavaScript (Vanilla)** - No framework dependencies for lightweight performance
- **Intersection Observer API** - Efficient scroll animations
- **LocalStorage** - Theme preference persistence
- **Formspree** - Serverless email form backend

## 🚀 Getting Started

### Local Development
1. Clone or download the repository
2. Open `index.html` in your web browser
3. For best experience, use a modern browser (Chrome, Firefox, Safari, Edge)

### Deployment
- **Vercel** (Recommended) - One-click deployment with Git integration
- **Netlify** - Git-based continuous deployment
- **GitHub Pages** - Free static hosting
- **Traditional Hosting** - FTP deployment to any web server

## ⚙️ Configuration

### Theme Customization
Edit CSS variables in the `<style>` section:
```css
:root {
    --accent-primary: #d97706;    /* Primary brand color */
    --accent-secondary: #ea580c;  /* Secondary accent */
    /* ... other variables */
}
```

### Social Links
Update social media URLs in the social sidebar and footer sections.

### Contact Form
The contact form uses Formspree. Update the form action URL with your Formspree endpoint.
